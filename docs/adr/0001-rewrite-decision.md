# ADR-0001: 从零自研新项目（Go 重写 + 薄前端），非二开

Status: accepted

Kanso 最初按"基于 Kaneo 二次开发"立项，经多轮权衡后定案为**从零自研**：Go 重写后端 +
React 薄前端 + SQLite 单机存储。kaneo（TS 原版仓库）仅作为领域模型与 UI 设计的
**参考**，其代码一行不复用；参考使命在 M1/M2 开发完成后已尽，参考仓库已移除。
无 Node 运行时依赖。

Consequences:

- 工作目录：`F:/golang/kanso`（新 git 仓库，根目录即新项目）
- 产品决策（共享密钥/单用户 admin/全权模式/砍计费集成附件）作为新项目的设计输入原样继承
- 不再有"跟随/分叉上游"的概念；参考仓库已移除

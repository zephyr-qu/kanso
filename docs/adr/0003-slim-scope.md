# ADR-0003: 产品范围——MVP 核心看板，扩展项后置

Status: accepted

从零自研背景下按成本重估功能范围：

**MVP 必做**：工作区/项目/列/任务（拖拽移动与排序）/标签/评论/活动记录/WebSocket 实时。

**后置候选**（MVP 验收后再逐个评估）：通知（站内）、搜索（FTS5）、自动化（Workflow Rule，
列变更触发动作）、工时（time-entry）、MCP/AI 集成（Go MCP SDK）、公开分享（只读公开页）。

**明确不做**：计费订阅（SaaS 专用）、第三方集成（GitHub/Slack 等，内网无用）、
附件/文件存储（内网无对象存储，需自写磁盘适配器，性价比低）。

Consequences:

- 数据模型仅需约 8 张核心表，单用户无用户/成员/角色/邀请表
- 后续每加一个扩展项按同样的"问题/取舍/落点"模式新增 ADR 决策

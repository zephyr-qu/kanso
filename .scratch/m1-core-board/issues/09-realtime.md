# 09 — 实时同步（WebSocket）

**What to build:** 两个浏览器同时打开时，任一页面的写操作（建任务、移动、贴标签、评论等）实时同步到其他页面，无需刷新；事件按项目隔离，只收到当前所在项目的事件；连接断开自动重连，重连后重新拉取数据收敛一致。API 缝测试以 WS 客户端订阅断言广播事件与项目隔离。

**Blocked by:** 07 — 标签、08 — 任务详情（等待全部写路径就绪后统一广播）

- [ ] 只收到当前项目的事件（项目隔离）
- [ ] 断线自动重连，重连后数据收敛一致

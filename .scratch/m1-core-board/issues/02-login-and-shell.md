# 02 — 登录与路由守卫

**What to build:** 用户首次打开 Kanso 看到登录页，输入 Access Key 验证通过后进入应用壳（导航框架与内容区占位）。密钥存于本地，刷新保持登录；服务端密钥变更导致 401 时自动清除本地密钥并回到登录页；未登录访问受保护路由被引导至登录页。

**Blocked by:** 01 — M0 收尾与 sqlc 铺底

**Status:** ready-for-agent

- [ ] 首次访问被引导到登录页；正确密钥通过后进入应用壳
- [ ] 错误密钥显示可读错误提示（不泄露密钥信息）
- [ ] 刷新后保持登录态，无需重新输入
- [ ] 服务端返回 401 时清除本地密钥并跳转登录页
- [ ] 应用壳提供导航框架（工作区入口 + 内容区占位），为后续页面提供挂载点

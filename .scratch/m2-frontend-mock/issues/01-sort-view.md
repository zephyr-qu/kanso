# 01 — 看板排序切换（显示层，限后端字段）

**What to build:** 看板顶部加排序切换器（字段 + 方向），按标题或创建时间对**当前列内任务**的显示顺序排序。这是显示层排序：只改变渲染顺序，不写回 position，拖拽或刷新后恢复原顺序。排序字段仅保留后端真实存在的两个（标题、创建时间）——优先级/截止日期/编号是前端预留字段，后端任务模型不存在，UI 不提供入口。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] 看板顶部排序切换器可见：字段选择（标题/创建时间）+ 方向（升/降）
- [x] 切换后当前列任务按所选字段/方向重排显示，其余列不受影响
- [x] 排序不修改任何任务 position（刷新/拖拽后恢复原顺序）
- [x] 排序 UI 无优先级/截止日期/编号选项（后端无字段）
- [x] Playwright 验证：切换字段与方向生效、position 不变

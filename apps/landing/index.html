部署在自己的机器上

一个容器，一个数据目录，一个自己定的访问密钥。

  • 数据落在 KANSO_DATA_DIR，整个目录跟着卷一起搬
  • 设置页可导出备份，也能用备份全量恢复覆盖
  • 个人模式不需要账号体系，团队模式按成员发密钥
shell docker compose 
git clone https://github.com/zephyr-qu/kanso.git
cd kanso
KANSO_ACCESS_KEY=$(openssl rand -hex 32) docker compose up -d
默认监听 8080，数据存在 docker 卷 kanso-data
